# Карточка ИИ-функции — интеллектуальный подбор питомца

| Поле | Содержание |
|---|---|
| **Функция** | Интеллектуальная рекомендательная система подбора домашних животных PetHome. Пользователь заполняет анкету (жильё, дети, другие животные, время, опыт, образ жизни) и пишет о себе в ИИ-чате. Система предлагает до 5 животных из базы приюта с объяснением, задаёт уточняющий вопрос или честно сообщает, что безопасных вариантов нет, и передаёт вопрос сотруднику. Анкета, чат и рекомендации — части одной функции |
| **Зачем** | Сейчас пользователь сам листает каталог из 50 карточек и фильтрует по 8 полям. Фильтры не учитывают сочетания условий («квартира + ребёнок до 6 + мало времени»), а свободный текст не понимают вообще. Неподходящие заявки — лишняя работа сотрудника и риск возврата животного |
| **Бизнес-метрика** | Конверсия из рекомендаций в заявку на усыновление: заявки с `recommendation_id` / сессии подбора, в которых были выданы рекомендации. **Цель: относительный рост на 15 % за два месяца.** Исторических данных нет, поэтому это целевой показатель, а не измеренный результат. Первые 4 недели фиксируем точку отсчёта, считается в `GET /admin/ai/stats` |
| **Метрика качества модели** | Классификация пар «запрос — животное» (Подходит / Не подходит / Недостаточно данных): Accuracy, Macro P/R/F1, F1 по классам. Ранжирование: Precision@5, Recall@5, NDCG@5. Безопасность: доля нарушений обязательных ограничений. Плюс корректность объяснений и время ответа. Правила расчёта — `evals/METRICS.md` |
| **Базовое решение без ИИ** | 18 правил: 10 жёстких, 4 правила неопределённости, 4 правила ранжирования. Учитывают вид, возраст, размер, породу, город, доступность, активность, жильё, опыт, время, детей, других животных, прогулки, характер, уход и подтверждённые ограничения (`evals/BASELINE_RULES.md`). Измеряется первым |
| **Критерий приёмки** | Функция включается для пользователей, если на 36 сценариях с разметкой людьми вариант D одновременно: (1) macro F1 ≥ 0,75 и **лучше baseline по F1 каждого из трёх классов**; (2) NDCG@5 не ниже baseline; (3) доля нарушений обязательных ограничений ≤ 2 % и ни одной рекомендации в сценарии «безопасных нет»; (4) среднее время ответа ≤ 5 с. Если хоть одно не выполнено, ИИ остаётся выключенным, работает подбор по правилам |
| **Что функция не делает** | Не одобряет и не отклоняет заявки, не принимает решение об усыновлении, не проводит платежи, не меняет сведения о животных и статусы. Не оценивает человека. Не видит ФИО и телефон из заявки. Модели не передаются данные аккаунта. Итог совместимости подтверждает сотрудник приюта |
