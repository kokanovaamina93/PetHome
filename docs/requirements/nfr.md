# Нефункциональные требования PetHome

| ID | Категория | Требование | Способ проверки |
|---|---|---|---|
| НФТ-01 | Производительность | Главная страница открывается не более чем за 1,5 с (p95) при 500 животных | Нагрузочный тест k6 |
| НФТ-02 | Производительность | Поиск животных выполняется не более чем за 1,0 с (p95) | Нагрузочный тест k6 |
| НФТ-03 | Масштабируемость | Система поддерживает 30 одновременных пользователей и 5000 записей животных | Нагрузочный тест |
| НФТ-04 | Доступность | Доступность системы составляет не менее 99% в месяц | Uptime Kuma |
| НФТ-05 | Безопасность | Пользователь может просматривать только собственные заявки | Автотест попытки доступа к чужой заявке |
| НФТ-06 | Разграничение доступа | В системе предусмотрены роли пользователя, сотрудника и администратора | Интеграционные тесты ролей |
| НФТ-07 | Аудит | Каждое изменение статуса заявки сохраняется с пользователем, датой, старым и новым статусом | Автотест журнала |
| НФТ-08 | Резервное копирование | Резервная копия создаётся ежедневно, хранится 30 дней, RPO = 24 ч, RTO = 4 ч | Тестовое восстановление |
| НФТ-09 | Персональные данные | Персональные данные хранятся на территории РК и удаляются/обезличиваются через 3 года | Проверка БД и конфигурации |
| НФТ-10 | Локализация | Интерфейс доступен на русском и казахском языках | Ручная проверка экранов |
| НФТ-11 | Доступность интерфейса | Контраст текста не менее 4,5:1, основные операции доступны с клавиатуры | Lighthouse/WAVE и ручной тест |
| НФТ-12 | Совместимость | Система работает в двух последних версиях Chrome и Firefox и при ширине экрана от 360 px | Playwright |
| НФТ-13 | Эксплуатация | Развёртывание выполняется командой docker compose up не более чем за 5 минут | Развёртывание на чистой машине |
| НФТ-14 | Миграция | При переносе каталога сохраняется 100% записей животных и их идентификаторов | Сравнение данных до и после миграции |
