## Главное правило защиты

Каждую цифру из отчёта можно открыть в файле и пересчитать командой, не обращаясь к ИИ:

```bash
python evals/score.py                                  # все метрики по прежнему эталону
python evals/score.py --gold evals/gold_v2.jsonl       # те же метрики по эталону v2
python evals/merge_labels.py --set v2                  # согласие разметок и Cohen's kappa
```

Скрипты берут сохранённые ответы модели из `evals/raw/…` и выводят ту же таблицу, что в отчёте.
Это и есть доказательство, что результаты не придуманы.

## Живая демонстрация (самое убедительное)

1. **Сайт с ИИ.** Локально: `python run_pethome.py` (ключ Groq — в `backend/.env`, в GitHub его нет).
   На https://pet-home-nine.vercel.app ИИ заработает после слияния ветки и настройки Render и Vercel.
2. **Подбор.** «Подбор с ИИ» → заполнить анкету → рекомендации с объяснениями и уведомлением
   «Рекомендации сформированы с помощью искусственного интеллекта…».
3. **Уточняющий вопрос.** Написать в чат коротко, например «хочу кого-нибудь милого» → система задаёт вопрос, а не подбирает наугад.
4. **Резервный режим.** У сотрудника → панель «ИИ-подбор» → выключить ИИ → подбор продолжает работать по правилам,
   с отдельным уведомлением. Там же видна статистика запросов и заявок.
5. **Проверка API.** `GET /ai/status` показывает, включён ли ИИ, задан ли ключ провайдера, модель и версию промпта.
6. **Пересчёт метрик** — команды из раздела «Главное правило защиты».

Скриншоты, если демонстрация не получится: `docs/lab12/img/` (рекомендации, уточняющий вопрос, передача сотруднику).

## Частые вопросы

- **«Модель настоящая или фильтры?»** Сырые ответы Groq с `system_fingerprint`, токенами и временем — в `evals/raw/…/B.jsonl`, `C.jsonl`.
  Правила — отдельный вариант A, и его результаты другие.
- **«Почему не включили для пользователей?»** Критерий приёмки не выполнен: ранжирование хуже правил, нарушений больше 2 %.
  Это и есть ответ ADR.
- **«Детерминированно ли?»** temperature 0, seed 42, но Groq поддерживает seed только в режиме best effort: за прогон few-shot было 20 разных `system_fingerprint`.
- **«Откуда разметка?»** Как написано в `evals/LABELING.md`: две предоставленные разметки, спорные случаи согласованы,
  происхождение разметки не подтверждено — поэтому задание 5 отмечено как «частично».
