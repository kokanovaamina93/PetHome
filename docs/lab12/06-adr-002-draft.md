# ADR-002. Включаем ли интеллектуальный подбор питомца

> **Статус: Предложено (черновик).** Решение «делаем / не делаем» принимается ПОСЛЕ замера на 36 сценариях
> с разметкой людьми. Разделы «Решение» и «Последствия» заполняются фактическими цифрами из `evals/results/`.

| Поле ADR | Содержание |
|---|---|
| **Статус** | Предложено, 24.11.2026. Ожидает: подтверждения карточек животных, разметки двумя участницами, прогона на Groq |
| **Контекст** | Пользователь выбирает животное вручную из каталога, фильтры не учитывают сочетания условий. Backend размещён на Render Free (512 МБ ОЗУ, засыпает через 15 минут), frontend — на Vercel. Сайт должен работать без компьютера команды |
| **Рассмотренные варианты** | 1) Не внедрять подбор. 2) Только правила (18 правил, вариант A). 3) Внешний облачный API (Groq, `openai/gpt-oss-20b`). 4) Открытая модель на своём сервере (Hetzner CPX42 / GEX45). 5) Гибрид: облачная модель + проверка обязательных ограничений правилами + отказ + правила как резерв |
| **Предварительные доводы** | Вариант 4 на Render невозможен (512 МБ ОЗУ при ≈ 5 ГБ для 7B-модели). Свой CPU-сервер — ≈ 109 $/мес против ≈ 0,44 $/мес у API при прогнозном потоке. Точка безубыточности ≈ 338 тыс. запросов/мес, это в ≈ 250 раз больше прогноза (`cost-model.xlsx`, предварительные токены). Вариант 5 — единственный, где ошибка модели не превращается в небезопасную рекомендацию: ограничения проверяются детерминированно |
| **Решение** | _после замера_ |
| **Почему не другие варианты** | _после замера: фактические macro F1, NDCG@5, нарушения по A/B/C/D_ |
| **Последствия: положительные** | _после замера_ |
| **Последствия: отрицательные** | Зависимость от внешнего провайдера и его тарифов (`llama-3.1-8b-instant` в 2026 году уже перевели на «Contact Sales»). Анкета и текст чата уходят за пределы РК. Нужен повторный прогон eval при каждой смене модели. Холодный старт Render Free до 1 минуты |
| **Критерий пересмотра** | Через 2 месяца: если конверсия из рекомендаций в заявку выросла меньше чем на 15 % относительно первых 4 недель, **или** на ежемесячной проверке доля нарушений ограничений > 2 %, **или** доля резервного режима > 10 % — функция отключается переключателем, решение пересматривается |
