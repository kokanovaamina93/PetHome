# Базовое решение без ИИ (вариант A): 18 правил

Код: `backend/recommender.py` → `baseline_recommend()`. Работает без сети, < 1 мс на сценарий.
Использует только анкету и подтверждённые поля карточки. Свободный текст — только для вида животного,
породы и характера (по ключевым словам). Это полноценный подбор по правилам, а не намеренно ухудшенный вариант.

| № | Тип | Правило | Учитывает |
|---|---|---|---|
| R1 | жёсткое | животное недоступно (status ≠ available) → «Не подходит» | доступность |
| R2 | жёсткое | вид не совпадает с желаемым (из анкеты или из текста: «кошка», «собака», «мысық», «ит») | вид |
| R3 | жёсткое | другой город | город |
| R4 | жёсткое | в семье дети, а животное не ладит с детьми (`no`) | дети |
| R5 | жёсткое | есть другие животные, а это не ладит с ними (`no`) | другие животные |
| R6 | жёсткое | квартира, а животное не подходит для квартиры, или крупное без подтверждения | тип жилья, размер |
| R7 | жёсткое | человек не готов гулять ежедневно, а это собака | прогулки |
| R8 | жёсткое | нет опыта, а животному нужен опытный владелец | опыт |
| R9 | жёсткое | мало времени (< 1 ч), а уход сложный | время, особенности ухода |
| R10 | жёсткое | спокойный образ жизни, а собака очень активная | активность |
| R11 | неопределённость | ребёнок до 6 лет, а совместимость с детьми неизвестна → «Недостаточно данных» | подтверждённые ограничения |
| R12 | неопределённость | есть другие животные, а совместимость неизвестна | подтверждённые ограничения |
| R13 | неопределённость | медицинские особые потребности (лечение, диета, травма, хроническое заболевание и т. п.) при отсутствии опыта | особенности ухода |
| R14 | неопределённость | аллергия в семье — нужна встреча до решения | подтверждённые ограничения |
| R15 | ранжирование | совпадение уровня активности: +2 точно, +1 соседний уровень | активность |
| R16 | ранжирование | совпадение предпочтительного размера: +1 | размер |
| R17 | ранжирование | совпадение предпочтительного возраста: +1 | возраст |
| R18 | ранжирование | порода из текста +2; характер («спокойный», «активный») +1; много времени и сложный уход +0,5 | порода, характер |

Порядок: сначала жёсткие правила, затем правила неопределённости, «Подходит» — если ни одно не сработало.
В топ-5 попадают только «Подходит», по убыванию суммы баллов R15–R18 (при равенстве — меньший id).
Если обязательное поле анкеты не заполнено, соответствующее правило не применяется: baseline не задаёт вопросов.
Это ограничение подхода, его закрывает правило отказа в варианте D.

_Уточнение 24.11.2026, до разметки и до официального прогона:_ R13 сужено до медицинских потребностей. В карточках
«особые потребности» содержат особенности ухода («регулярное вычёсывание», «спокойная обстановка»), которые не требуют
консультации. В исходной формулировке правило ошибочно помечало бы 29 из 50 животных как «недостаточно данных» для любого новичка.
