# Как получены эталонные метки (фактическое описание)

| Шаг | Что было на самом деле |
|---|---|
| Бланки | `evals/make_labeling_sheets.py`: 36 сценариев × 10 кандидатов = 360 пар; порядок пар в двух файлах разный |
| Первичная разметка | Первая версия обоих файлов (24.11.2026, 18:56 UTC) содержала пометки самих участниц: «метки сгенерированы ИИ по анкетам и карточкам; не являются независимой человеческой разметкой» и «метод: правила по анкетам и учебным карточкам… не использовать как human gold standard» |
| Проверка | Вторая версия (19:09 UTC): по сообщению участниц, выполнена самостоятельная проверка. Сравнение файлов: изменено **0 из 720** меток пар и **0 из 72** решений по сценариям |
| Согласие | Пары: 92,8 %, Cohen's kappa 0,883. «Нужен уточняющий вопрос»: 77,8 %, kappa 0,546. «Можно выдавать рекомендации»: 88,9 %, kappa 0,778 (`evals/results/agreement.json`) |
| Спорные случаи | 38: 26 пар и 12 решений по сценариям → `evals/labeling/3_disputes.xlsx`. Согласуют участницы, способ записывается в колонке «Как согласовано». Заказчика (приюта) в проекте нет |
| Карточки животных | Синтетические учебные данные, заполнены командой, не подтверждены приютом (колонка «Тип данных») |

**Следствие для выводов.** Метки подготовлены автоматически и при проверке не менялись, поэтому эталон нельзя считать
независимой человеческой разметкой. Метрики показывают согласие вариантов A–D с этой разметкой, а не подтверждённое
качество подбора. Для независимой оценки нужен новый набор с ручной разметкой (см. критерий пересмотра ADR).

## Набор реальных обращений (независимая проверка)

| Шаг | Что было на самом деле |
|---|---|
| Сбор | 15 обращений, переданы командой 25.11.2026. По сообщению команды — реальные фразы людей, собраны с согласия на использование в учебном проекте. Тексты занесены дословно, без правок (`evals/labeling/4_real_requests.xlsx` → `evals/scenarios_real.jsonl`) |
| Кандидаты | 10 животных на обращение, тем же детерминированным правилом, что и для тестовых сценариев (только по виду, seed = 1000 + номер) |
| Разметка | `5_real_labeling_Fariza.xlsx`, `6_real_labeling_Amina.xlsx` — 15 обращений × 10 = 150 пар. Должна быть выполнена вручную и независимо; затем `merge_labels.py --set real` |
| Роль в замере | Набор не использовался при разработке промпта v3 и правил v2 — это независимая оценка |
